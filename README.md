# 星栈班级小组件

星栈出品的 Windows 班级桌面组件软件，采用星计的 WPF 架构、界面与主题，整合倒计日和校园信息看板。

**当前状态：开发中。** 此仓库用于公开文档和安装包发行，源码保留在本地开发环境，不上传到本仓库。建立发行仓库不代表已经完成正式发行或实机验收。

## 功能与开发状态

- 独立倒计时/倒计日卡片、日期筛选、10 套明暗主题与 DIY、独立组件主题及背景透明度、AI 标语。
- 课表、单双周、临时调课、当前与下节课程、今日课表、课前提醒及静音时段。
- 日期与天气、值日、班级公告、学科文件夹、每日单词/古诗/自定义栏目、轮播和内容归档分配。
- 共享用户配置 AI 接口的每日内容生成、课表图片识别与编辑确认。
- 桌面组件布局、统一显示隐藏、位置恢复、配置导入导出、诊断日志与更新检查。
- QCDesk 授权与云存档接替尚待核对原项目源码、认证接口和存档格式。**旧 QCDesk 停止维护并由本软件接替原服务的计划，尚未完成线上上线。** 当前不承诺旧账户授权、设备绑定或云存档可以直接迁移。
- 本地 Release 构建和回归测试已通过；51 张离屏界面截图覆盖校园分类、10 套主题明暗模式和独立组件主题。网络协议使用模拟响应验证，实机混合 DPI、多屏、系统通知、真实 AI/天气服务和安装卸载尚未全面验收。

## 安装与使用

安装包将在 [Releases](https://github.com/loveqian-ccxk/XingStack-ClassWidgets/releases) 提供。当前没有已核验的正式安装包；如后续提供预览版，会明确标注其开发状态与已知限制。

目标平台为 Windows x64。实际系统要求、安装方式、版本号和升级注意事项会随具体安装包公布，请勿将开发工程的版本号视为已发布版本。

AI 标语和每日内容需要自行配置兼容接口、模型与密钥；课表图片识别还需要模型支持图片输入。图片识别先显示可编辑预览，确认后合并到本地课表。相关请求和数据处理方式见 [隐私说明](PRIVACY.md)。

## 数据与反馈

本地设置目录为 `%LOCALAPPDATA%\XingStackClassWidgets`。在版本升级、导入数据或未来迁移 QCDesk 存档前，请自行备份本地设置。

可以通过本仓库的 [Issues](https://github.com/loveqian-ccxk/XingStack-ClassWidgets/issues) 反馈问题。请注明软件版本、Windows 版本、显示缩放及复现步骤；不要提交 API 密钥、登录凭据或含个人信息的课表和存档。
